# CASHEW Meme Website

A responsive one-page meme website with a zoom-through intro.

## Run locally

Open `index.html` in your browser, or use a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch

Search and replace:

- `PASTE_CONTRACT_ADDRESS`
- `href="#"` on the Buy, X, and Telegram buttons
- Tokenomics figures if needed

## Deploy

Upload the entire folder to Vercel, Netlify, GitHub Pages, or any static host.
No build command is required.
